## Un producto, cinco experiencias conectadas

**Demy** ayuda a las academias educativas a coordinar administradores, docentes y estudiantes alrededor de la misma información operativa. Una API REST compartida conecta la landing pública, el espacio para administradores en tablet y experiencias móviles dedicadas para docentes y estudiantes.

| Experiencia | Propósito | Tecnología |
| --- | --- | --- |
| [Demy Landing](https://github.com/nistrahq/demy-landing) | Descubrimiento del producto, precios, equipo y contacto | Vite, Tailwind CSS, JavaScript |
| [Demy Admins](https://github.com/nistrahq/demy-admins) | Operaciones, matrículas, facturación y finanzas | Kotlin, Jetpack Compose |
| [Demy Teachers](https://github.com/nistrahq/demy-teachers) | Horarios docentes, reprogramación y asistencia | Flutter, Dart |
| [Demy Students](https://github.com/nistrahq/demy-students) | Horarios personales, novedades, perfil y configuración | Swift, SwiftUI |
| [Demy API](https://github.com/nistrahq/demy-api) | Capacidades de negocio e integraciones compartidas | Java 21, Spring Boot, MySQL |

## Nuestra dirección

Nistra crea software práctico para academias educativas en Perú. Con Demy buscamos que la administración diaria sea más organizada, transparente y accesible para todas las personas de la comunidad académica.
